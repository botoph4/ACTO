# 求解算法基准

测试场景：`M1 双臂搓线插线 + 中转平台`

- 动作数：40
- 执行单元：7
- 前置依赖 / 停止条件：45
- 求解器：OR-Tools CP-SAT
- 单次时间上限：60 秒
- 结果：5 次均得到 `optimal`，总周期 30.4 秒

本机连续 5 次求解耗时：

| 次数 | 耗时 |
|---|---:|
| 1 | 8.0 ms |
| 2 | 4.5 ms |
| 3 | 5.6 ms |
| 4 | 5.4 ms |
| 5 | 5.5 ms |

## 是否采用遗传算法

当前不采用遗传算法作为主求解器。

该模型是确定性离散资源约束调度问题。CP-SAT 可以利用区间变量、无重叠约束和优先关系直接搜索，并给出最优性证明。当前规模求解已低于 10 ms，遗传算法通常需要构造编码、解码、交叉、变异和大量适应度评估，很难在这个规模获得更短耗时。

遗传算法可以作为以下场景的后续扩展：

- 动作规模达到数百个，且 CP-SAT 经常触及时间上限；
- 目标函数引入难建模的非线性评分；
- 允许把 CP-SAT 的解作为遗传算法初始种群，用于局部探索。

## 当前防卡顿措施

1. 场景未变化时，前端直接提示“结果已是最新”，不再发请求。
2. 后端按请求内容哈希缓存求解结果，相同请求 0 ms 返回。
3. 单次求解硬上限 60 秒，避免异常约束导致长时间占用服务。
4. 返回可行解时标记为 `feasible`，不伪造“最优”状态。
5. 使用拓扑排序生成快速可行解提示，减少高重复批次寻找首个可行解的时间。
6. CP-SAT 默认以 1% 相对间隙优先保证响应速度，可通过 `ACTO_SOLVER_RELATIVE_GAP` 调整。
7. CP-SAT 工作线程默认按 CPU 数量扩展，可通过 `ACTO_SOLVER_WORKERS` 调整。

## 高重复批次基准

对 22 个动作、重复 40 次的胸部中转台场景进行验证：

- 调整前：2 秒内可能找不到首个可行解；使用 60 秒可得到 1175.7 秒批次时间。
- 调整后：默认 1% 相对间隙约 2.5 秒返回可行解，批次时间 1176.6 秒。
- 计算耗时约缩短 95.8%，批次时间差异约 0.08%。

该基准表明，延长绝对时限只应作为兜底；对重复模板使用可行性提示、合理终止间隙和并行搜索能显著降低响应时间。
